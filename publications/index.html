APEX-MEM uses an append-only property graph of temporally grounded, entity-centric events and a multi-tool retrieval agent to resolve evolving information at query time.

APEX-EM: Non-Parametric Online Learning for Autonomous Agents via Structured Procedural-Episodic Experience Replay

Pratyay Banerjee, Masud Moshtaghi, Ankit Chadha

APEX-EM introduced procedural knowledge graphs for LLM agent memory: its typed Procedural Knowledge Graph stores complete solution traces and retrieves them by meaning, operation structure, and graph traversal, with no model retraining.

Federated learningNAACL 2022 (Main Conference), pages 2576–2586

Training Mixed-Domain Translation Models via Federated Learning

Peyman Passban, Tanya Roosta, Rahul Gupta, Ankit Chadha, Clement Chung

Five domain-specific translation models use federated learning to build a mixed-domain neural machine translation system without pooling their data, with a method for selecting impactful parameters to control communication bandwidth.

Research contributionIntroduced a federated approach to mixed-domain neural machine translation and a bandwidth-control method that selects impactful parameters during federated updates.

WDRASS: A Web-scale Dataset for Document Retrieval and Answer Sentence Selection

Zeyu Zhang, Thuy Vu, Sunil Gandhi, Ankit Chadha, Alessandro Moschitti

WDRASS introduced a web-scale open-domain question answering dataset with 64,000 questions and 800,000+ labeled passages and sentences drawn from 30 million documents.
